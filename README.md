## Descrição do Projeto

Este projeto é um sistema simples de gestão de estoque desenvolvido em Python.  
O sistema permite cadastrar produtos, consultar os itens armazenados, registrar entradas e saídas de estoque, além de identificar produtos com quantidade abaixo de um limite definido pelo usuário.

Os dados são armazenados em um banco de dados SQLite, permitindo que as informações continuem salvas mesmo após o encerramento do programa.

## Objetivo do Sistema

O objetivo do sistema é simular uma aplicação básica de controle de estoque, aplicando conceitos de programação estruturada, funções, banco de dados e manipulação de informações.

O projeto foi desenvolvido como atividade acadêmica da disciplina de programação, com foco na organização lógica do código e no controle de produtos.

## Funcionalidades Implementadas

- Cadastro de produtos com:
  - Nome
  - Categoria
  - Preço
  - Quantidade inicial

- Consulta de produtos cadastrados

- Registro de entrada de estoque

- Registro de saída de estoque

- Verificação de estoque baixo com limite definido pelo usuário

- Armazenamento dos dados em banco SQLite

- Menu interativo no terminal

- Tratamento básico para:
  - Produto inexistente
  - Estoque insuficiente

## Tecnologias Utilizadas

- Python
- SQLite3
- Git
- GitHub
